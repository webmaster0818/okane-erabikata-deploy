住民税が払えない場合｜督促・延滞金・差押えまでの流れと減免・徴収猶予の申請

住民税を納期限までに納められないと、納期限後20日以内に督促状が送られ、督促状の発送から10日を経過すると差押えの対象になります（地方税法329条・331条）。令和8年の延滞金の率、退職後の普通徴収の注意、減免・徴収猶予・換価の猶予の要件と相談先を、条文と自治体の案内（2026年11月1日確認）で解説します。

住民税（個人の市区町村民税・都道府県民税）を納期限までに納められない場合、法律上は納期限後20日以内に督促状が送られ、督促状の発送から10日を経過しても完納しないと差押えの対象になります。一方で、地方税法には減免と徴収猶予・換価の猶予（1年以内・分割納付）の仕組みがあり、払えないと分かった時点で市区町村に相談することで使える可能性があります。本記事では、地方税法の条文（e-Gov法令検索）と自治体の公開情報（いずれも2026年11月1日確認）をもとに、流れと相談の方法を説明します。

結論

  • 放置した場合：督促状（納期限後20日以内）→ 督促状の発送から10日経過で差押えが可能 → 給与・預金・不動産などの差押え、という順に進みます（地方税法329条・331条）。
  • 延滞金：令和8年中は、納期限の翌日から1か月以内が年2.8%、1か月を超えた分が年9.1%です（横浜市の案内）。
  • 使える制度：失業・災害などで所得が大きく減った場合の減免（市区町村の条例による）と、1年以内の期間で分割して納める徴収猶予・換価の猶予があります。
  • 相談先：納税通知書を送ってきた市区町村の税務担当（納税課・収納課など）です。税務署ではありません。

住民税の納め方と、払えなくなりやすい場面

住民税の納め方には、本人が納付書や口座振替で納める普通徴収と、勤務先が給与から差し引いて納める特別徴収があります。

  • 普通徴収：地方税法320条により、納期は原則として6月・8月・10月・1月中で、市町村の条例で定めます。横浜市では、6月初旬に届く税額決定・納税通知書で「６月、８月、10月、翌年の１月の４回の納期に分けて」納めると案内しています。
  • 特別徴収：横浜市の案内では、勤務先が「毎年６月から翌年５月まで年12回に分けて」給与から差し引きます。

払えなくなりやすいのは、退職して普通徴収に切り替わったときです。地方税法321条の5第2項により、退職後の月の分は原則として勤務先が徴収しなくなり、残りを本人が納付書で納めることになります。ただし、6月1日〜12月31日に退職して本人が申し出た場合や、翌年1月1日〜4月30日に退職した場合は、最後の給与や退職手当から残りの税額が一括で差し引かれます（支払額が残額を超える場合に限ります）。住民税は前年の所得をもとに計算されるため、退職して収入が減った後に、前年の収入にもとづく税額の納付書が届くことになります。

出典：地方税法320条・321条の5（e-Gov法令検索）／納税の方法（横浜市）（いずれも2026年11月1日確認）

納期限を過ぎてから差押えまでの流れ

段階内容根拠
納期限の翌日から延滞金がかかり始めます。本来の率は年14.6%（納期限の翌日から1か月までは年7.3%）ですが、特例により令和8年中は年9.1%（1か月までは年2.8%）です。横浜市では、延滞金が1,000円未満の場合は納める必要がないとしています。地方税法326条・附則3条の2、横浜市
納期限後20日以内督促状が送られます（市町村が条例で別の期間を定めている場合があります）。横浜市ではハガキで届きます。地方税法329条
督促状の発送から10日を経過完納していなければ、徴税吏員は滞納者の財産を差し押さえなければならないとされています。地方税法331条1項
差押え以降給与・預金・不動産などを差し押さえ、取立てや公売をして滞納分に充てます。横浜市はこの一連の手続を「滞納処分」と説明しています。横浜市

出典：地方税法326条・329条・331条・附則3条の2（e-Gov法令検索）／延滞金について（横浜市）／督促状について（横浜市）／市税の滞納（横浜市）（いずれも2026年11月1日確認）

所得税の延滞税は「2か月」で率が変わりますが、住民税の延滞金は「1か月」で変わります。国税と地方税で区切りが違う点に注意してください。

払えないときに使える制度

1. 減免（税額そのものを減らす）

地方税法323条は、天災その他特別の事情がある人や、貧困により生活のため公私の扶助を受ける人などに限り、市町村の条例で住民税を減免できると定めています。対象は自治体ごとの条例で決まります。たとえば横浜市では、次のような場合が対象とされています。

  • 災害で住宅や家財が滅失した場合など
  • 生活保護を受けている場合、またはそれに準ずる場合
  • 前年の所得が一定額以下で、失職等により1か月以上所得がない場合、または所得が一定割合以上減った場合

横浜市では、自己都合退職と期間満了による退職は「失職等」に含まれないこと、申請は納期限までに必要であること、審査があり「申請によって必ず適用されるものではありません」ことも明記されています。

出典：個人市民税・県民税の減免及び森林環境税の免除について（横浜市）（2026年11月1日確認）

2. 徴収猶予（分割して納める）

地方税法15条は、災害・盗難、本人や生計を一にする親族の病気・負傷、事業の廃止・休止、事業の著しい損失などにより一時に納付できないと認められるとき、申請にもとづいて1年以内の期間に限り徴収を猶予できると定めています。猶予した金額は条例の定めにより分割して納めることができ、延長しても通算で2年までです。横浜市は、徴収猶予が認められると新たな督促や差押えなどの滞納処分は行われず、猶予期間中の延滞金の全部または一部が免除されると案内しています。

出典：地方税法15条（e-Gov法令検索）／市税の徴収猶予制度（横浜市）（いずれも2026年11月1日確認）

3. 換価の猶予（特別な事情がなくても申請できる）

病気や事業の休廃止などの事情がなくても、一時に納付すると事業の継続や生活の維持が困難になるおそれがあり、納税に誠実な意思がある場合は、申請による換価の猶予を受けられる可能性があります（地方税法15条の6）。申請の期限は「納期限から条例で定める期間内」とされており、横浜市では納期限から6か月以内です。猶予期間は1年以内で、横浜市は、申請する市税以外にすでに滞納している市税がある場合などは認められないとしています。

出典：地方税法15条の6（e-Gov法令検索）／換価の猶予制度（横浜市）（いずれも2026年11月1日確認）

4. 滞納処分の停止（生活が著しく窮迫する場合）

地方税法15条の7は、滞納処分できる財産がない場合や、滞納処分によって生活を著しく窮迫させるおそれがある場合などに、滞納処分の執行を停止できると定めています。仕組みの詳細は滞納処分の停止で解説しています。

相談の進め方

  1. 窓口を確認する：納税通知書や督促状に書かれている市区町村の担当課（税務課・納税課・収納課など）に連絡します。国税庁のFAQでも、住民税などの地方税は都道府県・市区町村が窓口とされています。
  2. 期限を意識する：減免は納期限までの申請が必要な自治体があり、換価の猶予にも申請期限があります。督促状を待たずに、払えないと分かった時点で連絡するほうが選べる手段は多く残ります。
  3. 状況を伝える：滞納している年度と期、払えない理由（失業・病気・収入減など）、毎月納められる見込み額を伝えます。
  4. 書類を準備する：求められる書類は自治体によって異なります。目安は税金の猶予・分納を申し出るときの準備書類と確認事項にまとめています。

出典：国税の納税の猶予制度FAQ（国税庁・PDF）（2026年11月1日確認）

差し押さえられた場合の注意

給与が差し押さえられた場合に手元に残る額や、預金が差し押さえられた場合の扱いは、給与を差し押さえられたときに手元に残る額の決まり方と預金の差押えについての誤解で解説しています。差押えの後でも、窓口への相談は続けてください。

納税のための借入れ・現金化について

住民税には減免・猶予の制度があり、猶予が認められれば延滞金も軽減されます。クレジットカードの現金化や給与ファクタリングなど、金融庁や消費者庁が注意を呼びかけている方法で資金を作って納めると、公的な制度で分割できたはずの負担を条件の悪い債務に置き換えることになります。まず市区町村に相談してください。

よくある質問

会社員ですが、住民税の滞納はありえますか

給与から差し引かれている（特別徴収）間は、本人が納め忘れることは通常ありません。退職や転職の間で普通徴収に切り替わったときや、副業などの所得分を普通徴収で納めているときに、納付書の支払いが遅れることがあります。

所得税と同じく税務署に相談すればよいですか

住民税の窓口は市区町村です。所得税については確定申告の所得税が払えない場合で解説しています。

自己破産すれば住民税は消えますか

租税等の請求権は、破産法253条1項1号により免責の対象外とされています（破産法253条（e-Gov法令検索）、2026年11月1日確認）。借金を整理しても住民税は残るため、市区町村への相談が必要です。

失業したら自動的に減免されますか

自動では適用されません。横浜市の例では、申請が納期限までに必要で、審査を経て判断されます。退職の理由によっては対象外になる点にも注意してください。退職後の国民健康保険・国民年金の負担については退職後の国保・年金の減免もご覧ください。

相談先

  • 市区町村の税務担当：住民税の減免・猶予・納付の相談。
  • 自立相談支援機関：税金以外にも支払いが重なっている場合の家計全体の相談。生活困窮者自立支援制度（厚生労働省）
  • 法テラス：借金が重なっている場合の法律相談。サポートダイヤル 0570-078374。日本司法支援センター

税金全般の分割・差押えの流れは税金が払えないときの分割納付に、複数の支払いが重なったときの考え方は滞納の優先順位にまとめています。

本記事は、法令と公的機関が公開している情報をもとに制度の一般的な仕組みを整理したもので、法的・税務上の助言ではありません。納期、減免の対象、猶予の申請期限や運用は市区町村の条例によって異なり、本文では横浜市の案内を例として挙げています。率や日付は2026年11月1日に確認した内容です。最新の内容はお住まいの市区町村でご確認ください。

お金に関するお悩みは、公的な窓口に無料で相談できます

支払いや返済が難しい場合、一般に、早い段階で相談するほど利用できる制度や猶予の選択肢が多くなります。 法テラス、消費者ホットライン188、お住まいの自治体の自立相談支援窓口など、無料で利用できる公的な相談先を相談先ディレクトリにまとめています。利用できる制度は個別の事情により異なるため、詳しくは各窓口にご相談ください。
